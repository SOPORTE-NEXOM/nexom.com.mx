Uso permitido del sitio

El usuario se obliga a utilizar el sitio de forma lícita, diligente y respetuosa. Queda prohibido:

  • Usar el sitio para fines fraudulentos, ilícitos o que lesionen derechos de NEXOM o de terceros.
